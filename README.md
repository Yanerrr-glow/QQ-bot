# QQ 群 AI 机器人框架（NoneBot2 + NapCat，默认接 DeepSeek）

把一个大模型接进 QQ 群，让它**像一个群成员那样聊天**。

它**不是**"记住对话历史"的那种聊天机器人：所有群消息逐条落盘，被 @ 时才现场组装 prompt ——
所以上下文成本可控，旧账也翻得动。

模型接口走的是 **OpenAI 兼容协议**：默认接 DeepSeek，但中转站、自建 vLLM、Ollama、
别的厂商的兼容端点都能加成一份**档案**，在控制台里点一下就切（见
[换一家模型接口](#换一家模型接口)）。

## 主要功能

- **群里 @ 它才回**，不抢话；唤醒词也能把它叫出来（概率与冷却可调）
- **人格三层**：底层人设 / 禁止事项 / 表层人设，权限由**文件划分**钉死 ——
  改人格只能编辑文件，聊天里没有任何入口
- **会自己学着改说话方式**：定期反思近期对话 → 逐个比对铁律 → 只写表层；
  撞到禁止事项**直接丢弃**
- **长期记忆**：跨会话、跨重启记得住；检索完全在本地算（**0 token**），按会话硬隔离
- **翻旧账**：每条消息建词面倒排索引，「上周谁说过来着」能查出**原始记录**
- **省 token 的上下文策略**：按固定间隔切分会话，上一轮的未读自动降级成"可压缩背景"
- **说话像真人**：一次回答里有多个短句时逐句分次发；按场合切换语气（日常 / 专注 / 安慰）
- **多模态**：图片下载、近似去重、由人格打分后入库；PDF 抽文本层，扫描版渲染后 OCR
- **联网搜索**：SearXNG / Tavily / 任意 JSON 端点三种后端，带限流与防注入渲染
- **换一家模型接口不用改代码**：控制台「模型」页里存多份档案（接口地址 / 密钥来源 /
  模型名 / 能力标记），点「设为当前」**下一条消息就生效**；`/模型 <档案id>` 在聊天里也能切
- **Web 控制台**：改参数即时生效；三层人设、记忆库、图片策略、表情包库都能看

## 快速开始

### 最省事：双击启动（Windows）

双击仓库根目录的 **`start-bot.cmd`**。它会：

1. 先跑一遍自检，把**缺什么**明确列出来（缺 Python、缺依赖都会指出来）
2. 缺的简单项（API Key、主人 QQ、角色名）**可以当场填**，直接写进 `.env`
3. 机器人起来之后，自动打开 Web 控制台 <http://127.0.0.1:8080/ai/>

> 前提：**NapCat 已经在跑**（本框架不代管它），并且 `.venv` 装好了 ——
> 第一次用请先按下面三步走一遍。

### 第一次：三步

```powershell
# 1) 装依赖（建 .venv，Python 3.12）
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
& '.\_工具链\安装依赖.ps1'

# 2) 配置：填 DeepSeek API Key（到 https://platform.deepseek.com/api_keys 申请）
Copy-Item '.env.example' '.env'
notepad '.env'

# 3) 起 NapCat，再起机器人（这一步也可以直接双击 start-bot.cmd）
& '.\_工具链\启动机器人.ps1'
```

NapCat 的启动方式随平台差异很大（Windows 注入 QQ / Docker / 独立部署），本框架不代管它。
你要保证的只有一件事：**OneBot 的 WebSocket 端口（默认 6700）在监听**。
日志里出现 `WebSocket connection established` 就是连上了。

> **机器上还没装 Python？** 去 [Releases](../../releases/latest) 下载 **`上手自检.exe`**，
> 双击就能跑（自带解释器）。它放在哪儿都行：会先在自己周围找这个仓库，找不到就问你路径。

### Linux / 服务器

`start-bot.cmd` 与 `_工具链\*.ps1` 都是 Windows 专属。Linux 上用 `.venv/bin/python bot.py`，
或走 [`deploy/README.md`](deploy/README.md) 那套 Docker（含 NapCat 掉线看护）。

## 换一家模型接口

接口走 OpenAI 兼容协议，所以**中转站、自建 vLLM、Ollama、别的厂商的兼容端点**都能用。
一份「档案」= 一家接口 + 一个模型，可以存好几份互相切：

1. 打开控制台 <http://127.0.0.1:8080/ai/> → **「模型」**页
2. 点「加一个档案（模板）」，把 `base_url`（如 `http://127.0.0.1:11434/v1`）、
   `model`（如 `qwen2.5:7b`）改对，**能力标记按实际勾**，保存
3. 点那个档案的**「测一下」** —— 它会真连一次接口，并列出对方有哪些模型
4. 点**「设为当前」** —— 下一条消息就生效，**不用重启**

也可以在聊天里切（限主人）：

```
/模型                 # 现在用哪家、哪个模型，有哪些档案
/模型 local           # 切到 local 这个档案（换接口 + 换密钥）
/模型 qwen2.5:7b      # 只覆盖模型名（接口不变）
/模型 默认            # 撤销覆盖，回到档案里写好的模型名
```

**密钥两种放法**：推荐在 `.env` 里放 `某变量=sk-xxx`，档案里只写变量名（`api_key_env`）；
也可以直接写在档案里 —— 控制台**只显示掩码**（`sk-a…cd`），保存时原样保留、不会明文回显。

**能力标记要如实填**（`vision` 读图 / `tools` 工具调用 / `logprobs` token 概率）：
端点不支持却收到相应参数会直接报 400，而那些失败看起来像"图坏了""搜索坏了"。
代码按标记主动取舍 —— 不读图的档案就不送图、不支持 tools 就不带工具表；
人设评估台的裁判会自动去挑一个能给出 logprobs 的档案（于是"便宜的本地上聊、
官方的打分"可以同时成立）。

旧的 `.env` 配置不用动：首次启动会按 `DEEPSEEK_*` **播种**一个叫 `deepseek` 的档案，
行为与以前完全一致。细节见 [`docs/开发日志.md`](docs/开发日志.md) 第 3 节。

## 换成你自己的角色

附带的 `persona_*.txt` 是一份**能直接用、也建议你替换**的示例人设。框架与人设完全解耦：

| 要改的 | 改成什么 |
|---|---|
| `persona_base.txt` | 你的角色的**身份与性格** —— 唯一必须重写的文件 |
| `persona_forbidden.txt` | 你的角色的**铁律**（逐条被解析，一条铁律能挡掉一条自动迭代的改动） |
| `persona_surface.txt` | 表层人设的初始内容。留空也行，自动迭代会往里填 |
| `.env` 的 `AI_CHAT_BOT_NAME` | **必须**与人设里的角色名一致 —— 写错了它会对着自己接话 |
| 唤醒词（控制台「唤醒」组，或 `.env` 的 `AI_CHAT_WAKE_WORDS`） | 改成你的角色名 / 昵称 |

写人设时两条经验：**一次只说一个主要意思**（极长的人设会把模型压成客服腔）；
**否定句别堆太密**（全篇「不许……」会让它过度克制、短到没话说，把核心几条改写成正向行为）。

改完本机**不用重启**（每轮回复前重新读）；容器部署下这三个文件是 COPY 进镜像的，要重新 build。

## 安全须知

1. **Web 控制台没有任何认证。** 它能看全部聊天记录、改全部配置、以机器人的 QQ 身份发言 ——
   所以端口必须只绑 `127.0.0.1`，远程访问走 SSH 隧道。
2. **`.env` 绝不入库。** 密钥一旦进了 git 历史，删文件也没用，必须吊销重发。
   控制台里密钥只以掩码显示（`sk-a…cd`），但控制台本身没有任何认证（见上一条）。
3. **挂小号。** NapCat 靠注入 / 第三方客户端工作，风控态度不明朗，主号被冻结不划算。
4. **`data/` 是别人的聊天记录。** 公开等于替所有群友做一次人肉，`.gitignore` 已排除。
5. **抓网页是受限的**（挡回环 / 内网 / 云元数据地址，每次重定向都重新查）—— 改这块别绕开检查。
6. **`/dsh` 只认主人、只做固定动作表里的动作**（任务文本作为一个 argv 元素传递，不经 shell）。
