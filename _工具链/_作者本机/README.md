# `_作者本机\`：只对作者环境有意义的脚本

这个目录里的脚本**不是框架的一部分**，克隆本仓库的人通常用不到 —— 它们依赖作者本机
特有的环境。放在这里是为了让 `_工具链\` 剩下的东西"每一个都可能跟你有关"。

| 脚本 | 为什么留在这里 |
|---|---|
| `dsh_agent.mjs` | DSH（作者自己的 agent 运行时）桥接：轮询取件、按白名单跑 `dsh headless`、回写结果。**没有 DSH 就没有取件方**，脚本本身跑不出意义 |
| `dsh_agent_daemon.mjs` | 上面那个 agent 的守护 / 自启（单实例、崩溃重启、计划任务安装与卸载）。Windows 计划任务专属 |

两者是配套的（守护用 `join(HERE, "dsh_agent.mjs")` 找 agent，所以必须同目录）。

机器人那一侧对应的是 `plugins/ai_chat/dsh_bridge.py`（`/dsh run <任务>` 那条指令）——
**两边要一起用才有意义**。只用机器人、不用 DSH 的话，这个目录可以整个忽略。

> 其它"仅 Windows 本机"的脚本（`安装依赖.ps1` / `启动机器人.ps1` / `自检.ps1` /
> `一键启动.ps1` / `启动隧道.ps1`）**不在这里**：它们虽然也只在 Windows 上跑，
> 但对任何自建的 Windows 用户都是可用的，所以留在 `_工具链\`。
> 这个目录的判据是"**只有作者能跑**"，不是"只在 Windows 能跑"。
