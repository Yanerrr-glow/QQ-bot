接口档案

一个档案 = 一家接口 + 一个模型（地址、密钥来源、模型名、能力标记）。 想换一家（中转站、自建服务、别的厂商的 OpenAI 兼容端点）就在这里加一个， 点「设为当前」下一条消息就生效，不用重启。 能力标记不是装饰：端点不支持 tools 却收到工具表会直接报错， 所以「工具 / 读图 / logprobs」要按实际情况勾。
字段：id（只能用字母数字与 _ . -）、label、 base_url、api_key（不建议直接写在这里）、 api_key_env（推荐：写 .env 里的变量名）、 model、vision / tools / logprobs。 本机端点（127.0.0.1 / localhost）留空密钥即可；active 是当前选中的档案 id。 deepseek 这个播种档案删不掉 —— 它是「回到 .env 默认」唯一的路。

人格包

人格现在是一个目录一套（persona/packs/<id>/）： 换角色 = 换目录，而不是覆盖同一批文件。 每个包的自我学习成果按包分开存（data/runtime/persona/<id>/）， 切回来接着用，不会串到别的角色身上。 切换立即生效 —— 下一次回复就是新人格，不用重启。

人格三层

v2 结构：底层人设只写身份与大方向，只有人能改（评估台也不能写）； 禁止事项与表层人设由人 / 评估台改； 情绪与关系在「行为矢量」里，示例按场景检索注入。 三层都是每轮现读，改完即生效（不用重启）。

语音包

一个语音包 = GPT 权重（.ckpt）+ SoVITS 权重（.pth）+ 参考音频 + 参考文本。 权重与参考音频都是 TTS 服务端（那台 Windows）上的绝对路径，容器里读不到； 权重留空 = 沿用引擎当前已加载的权重。两套权重必须是同一版本（v2 / v2ProPlus / v5 不能混用）， 混用不会报错但声音会坏。切换语音包只影响下一次 /语音，不用重启。
