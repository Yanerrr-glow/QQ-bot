# 架构与扩展（2026-10-22）

## 当前边界

```text
bot.py                         NoneBot 启动入口
plugins/ai_chat/
  __init__.py                  消息事件与业务编排
  context.py / llm.py           上下文与模型访问
  persona*.py / behavior.py     人格、反思、评估与行为约束
  memory.py / memstore.py       记忆业务与存储
  webui.py                     管理 API、认证、Web 首页响应
  web/console.html             Web 控制台模板
desktop/
  core/                        连接、凭据、HTTP、隧道（无 Qt）
  sdk/                         插件契约、权限、加载（无 Qt）
  gui/
    main_window.py             窗口、导航、连接与插件生命周期编排
    page_registry.py           内置页面注册与顺序
    plugin_bridge.py           插件 UI 契约的 Qt 适配
    base.py                    页面加载、失败恢复、异步回调失效
    features/catalog.py        功能目录及参数映射
    page_*.py                  具体页面
  plugins/                     独立桌面扩展
  selfcheck/                   桩服务与桌面自检
persona/packs/                 静态人格资产
data/runtime/                  机器人运行数据
.console/                      本机控制台数据
```

本次把约 860 行 HTML 从 Python 路由模块提取为模板，把内置页面注册、插件 UI 桥接从主窗口提取为独立模块。原有 `webui._HTML` 与主窗口页面常量导入继续兼容；模板按模块位置读取，不依赖启动工作目录。Docker 原有整目录复制可带上模板，发布导出与核对脚本已把 `.html` 加入白名单。

没有搬动业务模块的导入路径、部署入口或运行数据。现有插件有较多互相引用，整批移动到新目录会引入无关迁移风险。后续先提取职责，再按实际需求收拢包，不为扩展预造空目录。

## 新功能应该加在哪里

| 新增内容 | 扩展方式 |
|---|---|
| 新的机器人能力 | 在 `plugins/ai_chat/` 新增职责单一的模块，在入口挂事件；通过现有 config/settings 获取配置 |
| 功能开关与设置页 | 在 settings 声明参数，在 `gui/features/catalog.py` 登记展示；复用功能页构造器 |
| 复杂桌面页 | 继承 `Page`，实现 `_load`，在 `page_registry.BUILTIN_PAGES` 登记；标题当前承担导航身份，必须唯一 |
| 可独立启停的工具页 | 使用 `desktop/sdk` 和 `desktop/plugins/<id>/plugin.json`；不要直接依赖主窗口 |
| 新管理接口 | 服务端增加 API，同时更新桌面客户端、权限白名单及桩服务 |
| 新持久化状态 | 先声明权威路径、唯一写入者、恢复和迁移方式，再实现存储 |

## 页面交互契约

- 页面控件启动时建立，数据首次访问时加载；启动不再向 28 个页面同时发取数请求。
- 页面通过 `run_task` 执行后台操作；加载期间重复刷新合并，失败后允许再次加载。
- `invalidate()` 更换私有生命周期令牌；旧请求完成后不更新新目标页面。它不撤销已经发送的服务端写操作。
- 连接页的 `token` 仍是密码输入框，取消令牌改用 `_lifecycle_token`，避免同名覆盖。
- 搜索按标题和说明匹配，回车跳转，清空时恢复目录折叠状态；`Ctrl+K` 聚焦搜索，`F5` 刷新。
- 直接使用 `async_.run` 的特殊页面不自动获得 `run_task` 的失效保护，新增页面优先使用基类入口。

## 验证入口

项目根目录运行 `python -m desktop.selfcheck` 与 `python -m desktop.selfcheck.gui_smoke`。后者使用离屏 Qt 和临时配置，包含导航搜索、懒加载、过期回调、失败重试和连接页令牌冲突回归。

真实 SSH GUI 测试须显式设置 `QQBOT_SMOKE_SSH_ALIAS`，且别名应指向本机测试 sshd；默认跳过，避免原测试自动取用户的第一个真实 SSH 别名。
